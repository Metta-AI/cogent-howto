# This folder sets up a cogent

The person using you received this folder so you can become her cogent: her own agent with a name, memory, rules and guard rails.

When she says "set up my cogent" (or anything like it, such as "start", "let's begin" or "what is this?"), possibly from another folder ("set up my cogent from the cogent-howto folder in my Downloads"), find this folder, then read `for-your-agent/00-read-me-first.md` in it and follow it exactly, starting with its first step. Do not summarise this folder at her or explain Claude Code basics; she already uses Claude Code. If `~/cogent/BUILD-LOG.md` already exists, a cogent was set up from this folder before: say so in one line, and ask one question: continue that setup (read the log and resume), or start over?

If she says "continue setting up my cogent", read `~/cogent/BUILD-LOG.md` and `~/cogent/howto/for-your-agent/00-read-me-first.md`, then resume from the step the log records.
