# Handoffs
<!-- A handoff is written by /wrap-up when a task is unfinished. File name: YYYY-MM-DD-HHMM-<topic>.md (date and 24-hour time of writing). At session start the loader compares the newest handoff's filename time with the `updated: YYYY-MM-DD HH:MM` line at the top of brain/now.md. The newer one is shown; on a tie the handoff wins. A handoff older than 30 days is moved to brain/archive/. Cap: 40 lines each. -->

Format of a handoff file:

    # Handoff: <topic>
    Stopped at: <the exact point>
    Done so far: <what is finished and how it was checked>
    Next step: <the very next action>
    Open questions: <what is needed from her>
    Files: <paths touched>

Never write a password, key or ID number here.
