# Journal
<!-- This folder holds raw lessons, one file per month: YYYY-MM.md. -->

Format of a line in YYYY-MM.md:

    - YYYY-MM-DD <lesson> — why: <reason> (seen: N) [provisional]

Each lesson starts as provisional. When it has been seen twice, or she confirms it, it is promoted to a line in brain/claims.md first (HIGH if she said it, MED if seen twice). A claim about how she wants things done that reaches HIGH becomes a line in brain/rules.md. A provisional lesson older than 30 days that was never confirmed is moved to brain/archive/. Never write a password, key or ID number here.
